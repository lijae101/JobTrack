# JobTrack

A full-stack job application tracker built with Next.js, TypeScript and MongoDB. JobTrack helps users organize their job search, manage applications and keep track of their progress through a clean dashboard and Kanban board.

## Features

- **Authentication:** User registration and login using Better Auth.
- **Dashboard:** Overview of application statistics and recent activity.
- **Application management:** Create, view, edit and delete job applications.
- **Search and filtering:** Find applications and organize them by relevant criteria.
- **Kanban board:** Manage application progress across different statuses.
- **Persistent storage:** Store application data in MongoDB Atlas.
- **User-specific data:** Applications are associated with authenticated users.

## Getting Started

### Prerequisites

- Node.js
- npm
- A MongoDB Atlas account

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate into the project directory:

   ```bash
   cd jobtrack
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Create a `.env.local` file in the project root and configure the required environment variables.

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open [http://localhost:3000](http://localhost:3000) in your browser.
